## JSON(Javascript Object Notation):

1. Same Format everywhere
2. Easy data transfer between client and server
3. MongoDB - BSON
4. Lightweight and Redable

> Note:Refer j1.html

### Allowed Datatypes:

- string
- number
- object
- array
- boolean
- null

### Not Allowed Datatypes:

- function
- date
- undefined

### Accessing Values:

- Dot Notation (object.key)
- Bracket Notation (object['key'])
- Nested Object Notation (object.key.key)(object['key']['key'])
- Array inside JSON (object.array[index])

### Updating values of existing object key:

- Dot Notation object.key =new value
- Bracket Notation object["key"] = new value
- using variable object[key] = new value

> Note:Refer j2.html

### Javascript inbuilt Functions

- JSON.parse() -> string to object
- JSON.stringify() ->object to string
